# 🎥 MovieHub

![Banner MovieHub](https://raw.githubusercontent.com/AngeloGer/MOVIEHUB-PAM/refs/heads/main/assets/images/banner.png)

##### 🚧Atenção!🚧<br>O projeto está sujeito a alterações,<br>pois ainda está em desenvolvimento

O MovieHub é um projeto de aplicação mobile destinada ao gerenciamento, organização e visualização de filmes e suas informações principais.

## 🎯 Objetivo

O objetivo do projeto é criar um aplicativo simples que possa organizar listas de filmes, suas informações e outras que o usuário pode adicionar.

## Funcionalidades

O projeto possui:

- Tela de Login de usuários
- Tela de Cadastro de usuários
- Tela de Cadastro de filmes
- Navegação entre telas principais

## Como executar o projeto

### Requisitos
- Node.JS
- Editor de código

### Passo a passo
1. Clone o repositório
2. Acesse a pasta do projeto
3. Instale as dependências usando:

`npx expo install`

5. Aceite qualquer pergunta do terminal apertando Y, e depois da instalação execute:

`npx expo start`

O projeto vai iniciar e então você pode ver o projeto via seu celular (Expo Go), navegador ou um emulador de android.
